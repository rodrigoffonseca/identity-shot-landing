# Identity Shot — Landing Page

Landing page oficial do **Identity Shot**, hub de conteúdo sobre identidade digital, IAM e segurança.

🔗 **Site publicado:** https://rodrigoffonseca.github.io/identity-shot-landing/

## Conteúdo

- **Quem somos** — apresentação do hub e dos fundadores (Diego Oliveira e Rodrigo Fonseca)
- **E-book & artigos** — destaque para o e-book *Identidade & Acesso Descomplicados* e artigos sobre IAM
- **Podcast** — links para YouTube, Spotify e lives semanais no LinkedIn (toda sexta)
- **Mentoria** — apresentação da mentoria em Arquitetura de IAM (caso de estudo OmniRetail Group)
- **Contato** — formulário e links diretos para os fundadores

## Stack

Página estática em **HTML + CSS puro** (sem build step), com imagens embutidas em base64 — um único arquivo `index.html`, pronto para qualquer hospedagem estática.

## GitHub Pages

Publicado a partir da branch `master`, pasta `/ (root)`, em **Settings → Pages** deste repositório.

## Como editar

Todo o site está em `index.html`. Estilos ficam no `<style>` no topo do arquivo; as imagens (logo e capa do podcast) estão embutidas como `data:image` em base64, então não há pasta `assets` separada.
